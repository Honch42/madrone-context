Welcome to Madrone Context

A few things to set up before your first interview. Only the microphone and a Gemini key are required; everything else is optional.

Microphone & camera Checking
The microphone is required. The camera is optional and enables body-language analysis with Gemini models.
Gemini API key Checking
Required. Gemini transcribes your speech for every model. Get a free key from Google AI Studio.
Anthropic API key Checking
Optional. Enables the Claude models. Get a key from Anthropic.
OpenAI API key Checking
Optional. Enables the GPT models. Get a key from OpenAI.
Notes folder
Session notes and your Master Dossier are plain Markdown files. Point this at an Obsidian vault to see them there.
Recordings folder
Each recording is named with its session id, so it can always be matched to its note. Move this outside a synced vault if the files get large.
